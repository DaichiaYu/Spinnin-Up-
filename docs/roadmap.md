|---|---|---|
| 1 | 資料格式、28 個動作（含居家物品的範本）、線稿、動作總覽頁 | 完成 |

## 第 2 階段開始前要處理

- 倉庫已改成公開，用 GitHub Pages 上線。
- 手機實測項目：切到背景後計時還準不準、語音有沒有聲音、螢幕會不會自己暗掉。

## 之後要注意

- 計時用「開始時間和結束時間」算，不能每秒減一。
- 分享連結要帶版本號，動作用 `id` 記。
- 想邊看影片：靠手機的小窗播放。要實測小窗播放時，網頁的倒數和語音是否正常。

## 第 2 階段的做法（給接手的人）

- `index.html` 載入 `src/main.js`（瀏覽器原生的模組，沒有套件、沒有建置工具）。各檔案分工見 `AGENTS.md`。
- 課表只記在網址 `#r=` 後面，格式：`1;動作id.量.組數.休息秒~動作id.量.組數.休息秒;隔幾天.總次數`。開頭的 `1` 是格式版本。
- 讀到不認得的動作 id 會略過並提示；數字超出 `dose` 範圍會被拉回範圍內。
- 播放器用「這一步應該在幾點幾分結束」來算時間，每 0.2 秒檢查一次；網頁從背景回來時會自動補上經過的步驟，補的步驟不唸語音。
- 算次數的動作（`mode: reps`）不計時，等使用者按「做完了」。估總時間時一下算 4 秒。
- 左右分開的動作（`sided`）會拆成左邊、右邊兩步，中間 5 秒換邊。
- 行事曆是下載 `.ics` 檔，用重複規則（每 N 天、共幾次），活動裡附訓練連結。
- 播報有三種模式：語音＋提示音、只有提示音、全部靜音。語音和提示音的大小分開調（0–100%，相對於手機音量）。這組設定存在瀏覽器的 localStorage（`spinnin-up.sound`），不是身體資料。
- 播報時，畫面上對應的文字（動作名稱、提示的那一行、換邊）會變色；不說話的模式也會照同樣的時間點變色。用 `data-say` 標記要變色的元素。
- 「只有提示音」時，支援的瀏覽器會設 `navigator.audioSession.type = 'ambient'`，讓嗶聲不壓低影片。
- 提示音：倒數＝短嗶、開始＝高長音、這組結束＝低長音、換邊＝兩聲、完成＝上升兩聲。
- 播放時會要求螢幕不要自動變暗（瀏覽器支援才有效）。
- `window.__spin`（在 `src/main.js`）是給自動測試用的，不要拿掉。
- 2026-11-13 依測試回報（#1–#10）修正：行事曆欄位檢查、缺器材的動作不能加入、圖片說明改中文、桌機兩欄、標籤換行、按鈕至少 44px、計時畫面按鈕固定在底部、手機橫放兩欄、展開說明不被篩選列擋住、手機用系統分享選單。

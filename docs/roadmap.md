# 進度

| 階段 | 內容 | 狀態 |
|---|---|---|
| 1 | 資料格式、22 個動作、線稿、動作總覽頁 | 完成，等使用者看過動作清單 |
| 2 | 手動組課表、預覽和編輯、播放器（倒數、語音、圖）、分享連結、行事曆 | 還沒開始 |
| 3 | 初次問卷（尺寸、試做動作、偏好）、排課表的規則、做完回饋和調整 | 還沒開始 |
| 4 | 依實際使用紀錄修正 | 還沒開始 |

## 第 2 階段開始前要處理

- **倉庫目前是私人的。** 免費方案的 GitHub Pages 只能用在公開倉庫。要上線測試，得把倉庫改成公開，或改用其他免費主機（例如 Cloudflare Pages，可以接私人倉庫）。
- 手機實測項目：切到背景後計時還準不準、語音有沒有聲音、螢幕會不會自己暗掉。

## 之後要注意

- 計時用「開始時間和結束時間」算，不能每秒減一。
- 分享連結要帶版本號，動作用 `id` 記。
- 想邊看影片：把影片嵌在同一頁，讓網頁留在前景。
